# Linguagem de Programação em C

Repositório destinado à resolução e ao registro das listas de exercícios da disciplina de Linguagem de Programação, utilizando a linguagem C.

## Organização

- `lista-01/`: exercícios da primeira lista.
- `lista-02/`: exercícios da segunda lista.

## Tecnologias e ferramentas

- Linguagem C
- Visual Studio Code
- GCC/MinGW para compilação
- Git e GitHub para controle de versão

## Objetivos

- Praticar os fundamentos da programação em C.
- Desenvolver o raciocínio lógico e a resolução de problemas.
- Registrar a evolução dos exercícios utilizando controle de versão.
